Plantilla de invitación de boda digital, personalizable para cada pareja, con confirmación de asistencia individual.

Cada invitado recibe un enlace personal (/?c=CODIGO) con el que confirma su asistencia y la de los niños a su cargo, sin escribir su nombre ni iniciar sesión.

Secciones

Cada sección es un módulo independiente (HTML + CSS + JS) que se puede incluir o quitar según lo que elija cada pareja:

Portada con nombres y fecha
Cuenta regresiva
Lugares: ceremonia y recepción con mapa
Carrusel de fotos y galería completa
Programa del evento y código de vestimenta
Libro de mensajes
Mesa de regalos con lista de compra
Confirmación de asistencia (RSVP) con fecha límite
Tecnologías
Frontend: HTML, CSS y JavaScript, sin frameworks
Backend: Node.js + Express
Base de datos: PostgreSQL
